Why FloodLens?

A real, end-to-end data-science project — from documented public data to a deployable web app with API.

🌧️

Meaningful drivers

Combines rainfall, river discharge, water level, elevation, soil and land cover — not a single rainfall threshold.

📊

Compared & tuned models

Benchmarks Logistic Regression, Decision Tree, Random Forest and Gradient Boosting with hyperparameter search.

🧠

Explainable estimates

Every prediction shows the top contributing factors with magnitude labels — transparent, not a black box.

🧪

Tested pipeline

Automated tests for data cleaning, feature engineering, model loading, validation, API and page rendering.

🗂️

Prediction history

Local SQLite log of past predictions with probabilities and factors; easily cleared for demos.

🚀

Deployable for free

Lightweight Flask + SQLite stack with Procfile/render.yaml — runs on free hosting tiers.

Honest data policy

Real data first, transparent fallback

FloodLens builds on the CC0-licensed Flood Risk in India dataset from Kaggle. If the real CSV is unavailable, a clearly-labelled synthetic dataset with the same schema is generated so the pipeline still runs for demos — no fabricated real-world claims.

  • Documented source URL, license and feature dictionary.
  • Schema validation, outlier clipping and imputation.
  • Reproducible training → serialized model artifacts.
About the data

Tech at a glance

  • Backend: Python · Flask · Flask-WTF (CSRF)
  • ML: scikit-learn Pipelines (joblib-serialized)
  • Visuals: Plotly (interactive) · Matplotlib/Seaborn (EDA)
  • Frontend: Responsive HTML/CSS + vanilla JS · Jinja
  • Storage: SQLite (history only; no ORM)
  • Tests: pytest (16 tests)
