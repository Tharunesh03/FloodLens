Predict

POST/api/predict

Accepts JSON of environmental features and returns the classified risk level, per-class probabilities, confidence, top contributing factors and recommended precautions.

Request body:

{
  "Rainfall_mm": 120.0,               // required, mm
  "Temperature_C": 28.0,             // required, °C
  "Humidity_pct": 88.0,              // required, 0-100
  "River_Discharge_m3_s": 3500.0,    // required, m³/s
  "Water_Level_m": 6.5,              // required, m
  "Elevation_m": 80.0,               // required, m
  "Population_Density": 800.0,       // optional, default 500
  "Land_Cover": "Agricultural",      // Urban | Forest | Agricultural | Water Body | Desert
  "Soil_Type": "Clay",               // Sandy | Clay | Loam | Silt | Peat
  "Infrastructure": 0,               // 0 or 1
  "Historical_Floods": 1             // 0 or 1
}

Example response:

{
  "ok": true,
  "risk_level": "Critical",
  "risk_index": 3,
  "confidence": 0.94,
  "probabilities": {"Low":0.00, "Moderate":0.01, "High":0.18, "Critical":0.81},
  "important_factors": [ ... ],
  "model_version": "1.0.0"
}
Click "Try it" to see the response.

Metadata

GET/api/metadata

Returns model version, name, test metrics, class distribution and feature list. Open it directly:

Open /api/metadata →

Errors

  • Invalid JSON / non-JSON body → 400 Bad Request with {"ok": false, "error": "..."}.
  • Missing or out-of-range fields → 400 with a list of errors.
  • Model not trained yet → 503 Service Unavailable from /api/metadata.
  • Successful predictions return 200 OK.
