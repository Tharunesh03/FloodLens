About FloodLens

FloodLens is a complete data-science project: from raw data and EDA, through model training and tuning, to a deployable Flask web app with a JSON API. It is built for educational demonstration and portfolio use.

The project

FloodLens classifies a location's flood risk into four levels — Low, Moderate, High, Critical — using environmental and historical factors. It is designed as a realistic decision-support demo for disaster-management awareness, infrastructure planning, and community education. It is not an operational early-warning system.

Dataset

Preferred dataset: Flood Risk in India (Kaggle, CC0 Public Domain).

  • Source: kaggle.com/datasets/s3programmer/flood-risk-in-india
  • License: CC0 (public domain, no usage restrictions).
  • Features: latitude, longitude, rainfall, temperature, humidity, river discharge, water level, elevation, land cover, soil type, population density, infrastructure, historical floods, flood occurrence.
  • Geographic coverage: India.

If the real CSV is not present in data/raw/, the training pipeline automatically generates a clearly-labelled synthetic dataset of the same schema, so the full stack (training → API → UI) is demonstrable offline. The synthetic dataset MUST NOT be presented as real-world evidence.

Technology

  • Backend: Python, Flask
  • ML: pandas, numpy, scikit-learn (XGBoost optional), joblib
  • Visualization: Plotly (interactive), Matplotlib + Seaborn (EDA/PNG)
  • Frontend: Vanilla HTML/CSS/JS, Jinja templates
  • Storage: SQLite (prediction history only, no ORM dependency)
  • Tests: pytest

Limitations

  • Models trained on Indian data should not be assumed to generalize globally.
  • The synthetic fallback data reflects engineered correlations, not real measurements.
  • The 4-class risk target is derived from a continuous risk score plus the binary flood label; it is a hazard indicator, not a severity ground truth.
  • No time-series / temporal modelling is performed; cumulative rainfall is approximated via a proxy feature.
  • No real-time weather or sensor integration.
  • Class imbalance may exist and is mitigated by class weighting and macro-F1, but recall for Critical events is not perfect.
  • Distribution shift (climate change, land-use change) will degrade performance over time.
  • False negatives are dangerous; any high-risk reading must be cross-checked with official warnings.

Ethical considerations

FloodLens is an educational decision-support system, NOT an official emergency warning. Users should never ignore or delay action based on government warnings because of this tool. The model is probabilistic: it is calibrated to minimize overall classification error subject to emphasizing recall for high-risk classes, but false negatives and false positives will occur.

Future scope

  • Real-time ingestion from weather APIs (e.g., Open-Meteo, IMD, NOAA).
  • Spatiotemporal modelling with LSTM / Temporal Fusion Transformers.
  • GIS integration with open-source maps (Leaflet + OpenStreetMap).
  • IoT water-level sensor integration for local deployments.
  • Continuous monitoring and retraining pipelines.
  • Multi-region training datasets for broader geographic coverage.
  • Alerting via email / SMS / mobile apps.
